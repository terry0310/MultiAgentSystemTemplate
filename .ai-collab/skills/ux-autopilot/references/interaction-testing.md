# Interaction tester

Use the authorized build, target device or window and input method named in the verification request. Confirm build identity and prerequisites. For an OS-level driver, confirm the target is foreground before sending input and capture only the authorized surface. Stop on loss of target, permission denial or interference with another user's session.

For each step record the input, observed outcome, the next user action, and evidence. When a menu overlaps a target, establish where the event actually landed. Check focus with an observable action or selection state. Record ambiguous observations as unverified and explain any device or timing limit. Return evidence to the verifier for the current round report.
